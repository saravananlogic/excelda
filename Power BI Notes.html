Power BI Fundamentals

What is Power BI?

Power BI is a self-service, cloud-based business intelligence tool from Microsoft that provides interactive visualizations and business intelligence capabilities with an interface simple enough for end users to create their own reports and dashboards.

Data Analysis

Data Analysis is telling a story with the data. It's a process of identifying, cleaning, transforming, and modeling data to discover meaningful information.

Building Blocks of Power BI

📊 Datasets

Collection of data from one or more sources that are cleansed, transformed, and modeled.

📈 Visualizations

Visual representation of data, such as charts or color-coded maps.

📋 Reports

Collection of visualizations on one or more pages.

📱 Dashboards

Collection of visuals on a single page that you can share with others.

🔲 Tiles

Single visualization on a dashboard that can be embedded in Apps.

Data Formats & Storage

🗄️

Database

Well-organized filing cabinet for storing data. Designed to record and manage data for specific tasks. Optimized for fast queries and transaction processing.

🏛️

Data Warehouse

Historical archive storing data from multiple sources over time. Purpose is to analyze and gain insights from historical data. Optimized for analytical processing.

Types of Queries

📥 Import

Import data to local machine (creates a local copy)

🔗 Direct Query

For huge datasets, keeps data at source level without burdening your software

🏞️ Direct Lake

Newer technology combining benefits of both Import and DirectQuery modes

Data Errors Resolution

  • Query Optimization: Hardware being used by concurrent users
  • Timeout Errors: Indicates too much data being pulled
  • Couldn't Find File: Caused by change in file location
  • Couldn't Find Data: Power BI expects data in table format
  • Data Type Errors: Data fetched with mismatched datatypes

Data Modeling

📋

Dimensional Tables

  • Describes business entities
  • Includes products, people
  • Typically smaller in size
  • Limited to groupable items
  • Examples: Customer Table, Product Table
📊

Fact Tables

  • Stores observations or events
  • Sales orders, stock balances, exchange rates
  • Usually larger than dimension tables
  • Stores numerous events
  • Examples: Sales Table

Schema Types

⭐ Star Schema

Popular method where each table is defined as either dimension or fact table. Central fact table surrounded by dimension tables.

❄️ Snowflake Schema

Tables can be related to dimension tables also. More normalized structure with dimension tables having relationships to other dimension tables.

Relationship Types

One-to-Many (1:M)

One student can read many subjects

Many-to-One (M:1)

Many subjects can be read by one student

One-to-One (1:1)

One student will have one registered number

Many-to-Many (M:M)

Many students can attend many sessions

DAX - Data Analysis Expressions

What is DAX?

DAX is a set of library functions provided by Microsoft to create measures, calculated columns, and calculated tables. It uses Excel-like syntax that's simple and intuitive.

⚡

Measures

  • Aggregated values as per business requirement
  • Created on demand
  • Always created on Fact Tables
  • Do not occupy space in dataset
  • Types: Explicit, Implicit, Quick Measure
📊

Calculated Columns

  • Generate row-wise data
  • Can be created on both table types
  • Occupy space in dataset
  • Affects performance
  • Use sensibly

Key DAX Functions Comparison

Function Description Context Behavior Example Use Case
ALL() Removes all filters from specified column/table Ignores all filters applied in report/visuals Returns total sales, ignoring all filters
ALLSELECTED() Removes filters but keeps user selections Respects user selections in slicers/visuals Returns total based on user-selected values
ALLEXCEPT() Removes all filters except specified columns Keeps filters on specified columns only Returns total sales per region, ignoring other filters

DAX Syntax Elements

Expressions

Combination of constants, operators, functions, and references

2 + 2 or SUM(sales[quantity])

Constants

Fixed values that don't change

42, "Hello", DATE(2020,12,31)

Operators

Symbols that perform operations

+, -, *, /, &, =, <>, IN

Functions

Predefined calculations

SUM, AVERAGE, IF, CALCULATE

Example DAX Formulas

All = CALCULATE(SUM(Sales[Sales]),ALL(Region[Region])) Sales Rank by Region = IF( HASONEVALUE('Region'[Region]), RANKX( ALL('Region'[Region]), CALCULATE(SUM('Sales'[Sales])), , DESC, DENSE ), BLANK() ) PreviousMonth = CALCULATE(SUM(Sales[Sales]),PREVIOUSMONTH('Date'[Date]))

Power Query Parameters

DAX Considerations & Limitations

⚡ Performance

Complex formulas can impact performance. Use calculated columns for static values, measures for dynamic calculations.

💾 Memory

DAX calculations consume memory. Be mindful of large datasets and avoid memory-intensive functions.

🔄 Dependencies

Understand calculation order and avoid circular dependencies.

🎯 Filter Context

CALCULATE function evaluates expressions in modified filter context. Be aware of filter propagation.

📊 Data Types

DAX is type-sensitive. Ensure consistent data types in calculations.

🧪 Testing

Always validate formulas with sample data and test edge cases.
